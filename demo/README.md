# Recorded decision audit

Open `index.html` beside `assets/`. The demo runs locally without a server, GPU, or model download.

This is the earlier **18-episode, 54-state** cohort with 42 frozen scorers. It is separate from the [completed 36-episode trajectory study](../docs/trajectory-results.md). Source videos show recorded policy execution, not generated futures. Helpful, harmful, and tied choices are all retained.

To reproduce its arithmetic, run the audit command in the main README. Edit `scripts/demo_template.html` and rebuild with `scripts/build_demo.py` to change the presentation. Inputs, outcomes, and media provenance remain fixed.
